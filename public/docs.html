Helvetfolio

A Swiss stock portfolio tracker that syncs live prices from Yahoo Finance directly into your Actual Budget accounts. Run it as a web UI, background daemon, or one-shot CLI — all from a single Docker image.

🚀 Quick Start

Up and running in under a minute with Docker Compose.

1. Start the web UI

docker compose up -d helvetfolio-web

Open http://localhost:3000 in your browser.

2. Connect to Actual Budget

Click Settings in the top-right, enter your Actual Budget server URL and password, then click Test Connection & List Budgets to pick your budget.

3. Add your first stock

Click Add Stock, enter the ticker (e.g. NESN for Nestlé — the .SW suffix is added automatically), quantity, and optional purchase date & price.

4. Sync prices

Click Update Prices to fetch the latest quotes from Yahoo Finance and push balances to Actual Budget. Or run the daemon for automatic syncing:

docker compose up -d helvetfolio-daemon

⚙️ Start Modes

Three modes — one image. Choose based on how you want to run Helvetfolio.

ModeDescriptionCommand
web Express web UI on port 3000. Manage portfolio, edit inline, sync manually. MODE=web
daemon Headless background process. Syncs prices on a cron schedule (default every 60 min). MODE=daemon
cli One-shot commands: add, remove, list, sync, update. MODE=cli (default)

Docker Compose services

# Start web UI
docker compose up -d helvetfolio-web

# Start background daemon
docker compose up -d helvetfolio-daemon

# Run one-shot CLI command
docker compose run --rm helvetfolio list

✨ Web UI Features

A clean, responsive portfolio table with everything you need to manage Swiss stock positions.

📊

Portfolio Table

View all positions with ticker, name, quantity, purchase date, buy price, cost basis, current price, current value, and gain/loss — all in one table.

✏️

Inline Editing

Click any editable cell to update quantity, purchase date, or buy price directly in the table. Changes sync to Actual Budget immediately.

🗂

Stock Grouping

Organise positions into named groups with aggregate value and gain/loss. Collapse, rename, and delete groups. Each position is keyed by its unique Actual Budget account ID, so duplicate tickers work correctly.

↕️

Column Sorting

Click any column header to sort ascending or descending. Sort by ticker, quantity, purchase date, buy price, cost basis, value, or gain/loss.

🔄

Price Sync

Fetch live prices from Yahoo Finance with one click. Dual timestamps show the last successful Yahoo Finance fetch and the last Actual Budget write separately.

🔒

Password Protection

Optional web UI password. Set via WEB_PASSWORD env var or through the Settings panel. Shows a branded sign-in modal instead of the browser's native auth dialog.

🗂 Stock Grouping

New in v1.2.0 — organise your portfolio into named groups with aggregated totals.

Creating a group

Each stock row has a small ＋ Group tag below its name. Click it to open the assignment dropdown, then choose ＋ New group and enter a name.

Assigning stocks

Click the group tag on any stock to reassign it. Existing groups appear in the dropdown — select one to move the stock, or choose No group to unassign.

Group actions

  • Collapse / expand — click the ▼ chevron or the group name.
  • Rename — double-click the group name label.
  • Delete — hover the group header to reveal the ✕ button. Member stocks are unassigned, not deleted.

Duplicate tickers

Multiple positions of the same fund (same ticker, different purchase date) are each tracked as a separate Actual Budget account. Group assignment is keyed on the unique accountId, so each position can independently belong to any group.

🔒 Authentication

Protect the web UI with a password. No restart required to change it.

Setting a password

Two ways — whichever takes precedence:

  • Env var (hard override): set WEB_PASSWORD=yourpassword in docker-compose.yml or .env. Cannot be changed from the UI while the env var is set.
  • Settings panel: enter a password in the Web UI Password field and save. Persisted to portfolio.json. Can be removed with the Remove Web Password button.

How it works

Static assets (index.html, app.js, styles.css) are served without authentication so the page loads first. All /api/* routes require a valid Authorization: Basic header. A 401 from any API call triggers the branded sign-in modal; credentials are stored in sessionStorage for the tab session.

🔌 API Reference

All endpoints return JSON. When a web password is configured, include an Authorization: Basic base64(:password) header.

Portfolio

MethodPathDescription
GET/api/performanceFull portfolio with gain/loss, groups, and sync timestamps
GET/api/portfolioLightweight portfolio summary (no Actual Budget required)
POST/api/update-pricesFetch fresh prices from Yahoo Finance and sync to Actual Budget
